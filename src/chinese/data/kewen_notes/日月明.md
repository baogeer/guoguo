## 会意字（部件 → 整字）

- 日 + 月 → 明（míng）
- 田 + 力 → 男（nán）
- 小 + 大 → 尖（jiān）
- 小 + 土 → 尘（chén）
- 二人 → 从（cóng）
- 三人 → 众（zhòng）
- 双木 → 林（lín）
- 三木 → 森（sēn）

## 词语

- 日月（rì yuè）
- 不成（bù chéng）
- 独木（dú mù）
- 一条心（yì tiáo xīn）
- 黄土（huáng tǔ）
- 变成（biàn chéng）
