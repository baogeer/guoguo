# 声母 l 与单韵母的拼读

> 本笔记从源图提取，图中为空白的声调位置已省略。
> 字迹不清或拿不准的例词用 `?` 标出，核验时请覆盖掉。

## 两拼音节

### l + a → la
- lā — 拉手（lā shǒu）
- lá — 旮旯（gā lá）
- lǎ — 喇叭（lǎ bā）
- là — 辣椒（là jiāo）

### l + e → le
- lē — 肋脦（lē de）
- lè — 快乐（kuài lè）

### l + i → li
- lí — 离开（lí kāi）
- lǐ — 里面（lǐ miàn）
- lì — 华丽（huá lì）

### l + u → lu
- lū — 撸串（lū chuàn）
- lú — 庐山（lú shān）
- lǔ — 卤菜（lǔ cài）
- lù — 马路（mǎ lù）

### l + ü → lü
- lǘ — 驴子（lǘ zi）
- lǚ — 旅游（lǚ yóu）
- lǜ — 绿色（lǜ sè）

## 三拼音节

### l + u + o → luo
- luō — 啰嗦（luō suo）
- luó — 萝卜（luó bo）
- luǒ — 赤裸（chì luǒ）
- luò — 落下（luò xià）
